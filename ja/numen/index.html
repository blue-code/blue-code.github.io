NUMEN：数学を、感じなおす

公式に頼らない、目で見る学び直し

Education · iPhone · iPad · 無料ダウンロード

App Store で見る

「公式を覚えるのではなく、わかりはじめる、その瞬間。」

NUMENは問題集アプリではありません。

数学をあきらめた人が、もう一度、数学的な直感をとり戻すためのアプリです。

このアプリは、ちがいます

これまでの数学アプリ：

定義 → 公式 → 演習 → 不正解

NUMEN：

体験 → パターン発見 → 直感 → 定義

指で直接ふれて、スライダーを動かし、値が変わるのを目で見ます。分数のひとかけら、関数のグラフの一点、負の数の向き — すべての概念が「動く数学」として、もう一度よみがえります。

だれのためのアプリ?

  • 授業が途切れて数学をあきらめた中学生・高校生
  • 塾式の説明に疲れた方
  • 投資・統計・AIを理解したい社会人
  • 「あのとき、頭が悪かったわけじゃない」を、もう一度感じたいすべての方

おもな機能

  • 指でふれるインタラクティブなレッスン

33レッスン、10フェーズ — 感覚・関係・変化・偶然・かたち・回転・極限・傾き・積み重なり・方向

  • 直感が先、定義はあと

まず現象を見て、パターンを見つけ、それから定義が来ます

  • 1日5〜10分のセッション

軽く、それでいて確かに、感覚をとり戻す

  • 連続記録（ストリーク）

毎日すこしずつ、途切れないように

  • 5言語対応

韓国語・英語・日本語・中国語（簡体字・繁体字） — すべてのレッスン本文を翻訳

  • iPhone・iPad ユニバーサル
  • 完全オフライン

広告なし、通信なし、個人情報の収集なし

なぜ NUMEN?

数学ができなかったのではありません。

概念と概念のあいだの — つながりが切れていただけ。

NUMENは、その糸を — 手で結びなおせるように — 設計されました。

「ああ、頭が悪かったんじゃない。

つながりが、切れていただけなんだ。」

そのひとことに、もう一度出会ってください。

プライバシー第一

NUMENはいかなる個人情報も収集しません。学習の進度はすべて端末の中だけに保存されます。広告SDK、解析ツール、外部API — どれもありません。

価格

  • アプリのダウンロード — 無料
  • Phase 1〜3（12レッスン、約60分）— 無料
  • Phase 4〜10（21レッスン）— 一度きりのアプリ内課金で、永久に解放。広告も、サブスクも、更新もありません。
