StoryLoom - 小説の人物相関図・設定資料

キャラの関係を一枚の地図に。プロットも年表も

Productivity · iPhone · iPad · 無料ダウンロード

App Store で見る

StoryLoom は、小説・ウェブ小説の作家のための人物相関図と設定資料ノートです。人物・関係・出来事・分岐を一枚の図に織り上げ、いつでもまるごと書き出せます。

ウェブ小説・小説・シナリオ・ウェブトゥーン・TRPG・二次創作 — 人物が増え、関係がもつれ、ルートが分岐すると、全体の形が見えなくなります。StoryLoom はその形を目に見えるようにします。人物はノード、関係は糸、出来事はタイムライン、分岐はルート。

五つのパートで物語を織る

  • 作品 — タイトル・ログライン・ジャンル・表紙色で世界観の単位を作り、自由に行き来。
  • 人物 — 名前・役割・ひと言で素早く記録し、背景や性格タグへ育てる。
  • 相関図 — 中核機能。人物ノードを手でドラッグして配置し、曲線の糸でつなぐ。関係ごとに種類(家族・恋人・友情・同盟・ライバル・敵対・師弟)、方向、そして –100〜+100 の好感度を設定可能。糸の色が関係の性格を物語る。
  • タイムライン & 分岐 — 出来事を順に積み、マルチエンディングやルートを分岐で枝分かれ。非線形の物語も構造が見える。
  • 書き出し — ワンタップで作品全体を Markdown / JSON のストーリーバイブルへ。バックアップも、他ツールへの移行も自由。

相関図 — 物語を見る新しい方法

複雑な人間関係を表ではなく地図として見る。ノードをドラッグして並べ、ピンチで拡大・移動、ノードや糸をタップしてその場で編集。誰が誰を愛し、誰と袂を分かったか — 色と曲線だけで一目でわかる。この一画面が StoryLoom のすべてです。

主な機能

  • 人物プロフィール(役割・ひと言・背景・性格タグ・アバター色)
  • 方向性のある関係 + 好感度グラデーション(冷たい緊張 ↔ 温かい絆)
  • 分岐するタイムライン、ドラッグで並べ替え
  • iPhone / iPad / Mac に対応。大きな画面では3カラム分割と広い相関図キャンバス
  • ライト/ダークモード、温かい紙とインクのエディトリアルデザイン
  • 初回起動から中身の入ったサンプル世界 — 空白ではなく、生きた相関図から
  • AI アプリの回答を反映(Pro)— お使いの AI アプリが原稿から抜き出した人物・関係・出来事をプレビューしてまとめて反映(StoryLoom 自体に AI は入っていません)

あなたの世界は、あなたのもの

初期設定では端末内に保存されます。設定で iCloud 同期を有効にすると、作品・人物・相関図・タイムラインを Apple の非公開 iCloud 領域経由で iPhone・iPad・Mac 間に同期できます。別アカウント、StoryLoom のサーバー、広告、追跡はなく、開発者が作品内容を見ることもできません。Markdown/JSON への書き出しもいつでも可能です。

無料で始めて、買い切りで永久解除

無料:作品2つ、作品ごとに人物15人、フル機能の相関図、分岐ルート1つ、Markdown 書き出し(下部に小さな「Made with StoryLoom」一行)。

Pro(買い切り永久解除):作品・人物無制限、分岐ルート無制限、相関図の自動配置、AI アプリ回答の反映と Siri・ショートカット連携、すっきりした Markdown + JSON + .storyloom バックアップ書き出し(フッターなし)。サブスクではありません。
