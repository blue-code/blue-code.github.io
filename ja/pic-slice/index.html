あなたの写真で楽しむ、オフラインスライドパズル

ピクスライス(PicSlice)は、お気に入りの写真で作るオフラインの写真パズル/スライドパズルゲームです。写真を3×3から6×6の正方形タイルに切り分け、クラシックな15パズルのようにスライドさせて元に戻しましょう。1分の通勤休憩にも、30分の週末チャレンジにも最適です。

主な機能

  • 3つのゲームモード
  • スライド: 空きマスを使って隣のタイルを動かす定番モード
  • 自由交換: 任意の2枚をタップで入れ替える自由モード
  • タイムアタック: 60/90/120秒以内に完成させるスピードモード
  • 4段階の難易度: 3×3 / 4×4 / 5×5 / 6×6
  • 3つの写真ソース
  • 厳選されたサンプルギャラリー(すぐ遊べる)
  • 写真ライブラリ(PHPicker 使用 — 通常権限ダイアログなし)
  • カメラで撮影
  • 個人統計: ベストタイム / 最少手数 / クリア回数(グリッド × モード別)
  • 触覚フィードバック + 60fps の滑らかなアニメーション
  • 日本語 / 한국어 / English / 简体中文 対応
  • ダークモード + ダイナミックタイプ + VoiceOver

本物のプライバシー

  • 通信ゼロ。写真は端末外に一切送信されません。
  • 広告なし、トラッカーなし、ログインなし、IDFA なし。
  • 100% オフライン — 機内モードでも同じように動作します。
