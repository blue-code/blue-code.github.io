Harudam 私密离线日记

语音备忘·地图·锁定日记

Lifestyle · iPhone · iPad · 免费下载

在 App Store 查看

Harudam 是一款一次买断、没有订阅的私密日记，用照片、地点和心情记录每一天。

不必写很长。一句话、一张照片、当天的心情，就能让普通的一天在未来变得值得回看。随着记录累积，你会拥有自己的时间线、心情日历和回忆地图。

无需账号。无月度订阅。默认只在本机。想在 iPad 上接着写，可以自己开启 iCloud 同步。

快速记录一天

  • 一句话日记
  • 语音备忘 — 说出来的一天会在设备端转成文字
  • 听写 — 按住麦克风说话，文字直接进入正文
  • 排版工具：标题、引用、列表、复选框
  • 照片日记
  • 视频 — 按你选的画质压缩，每篇一段
  • 手绘与扫描 — 用 Apple Pencil 画画，把旧信件扫描留存
  • 心情记录
  • 自动填入地点与天气 — 事后补写也用当天的天气
  • 添加照片后会询问是否改到拍摄那天，并使用照片的地点
  • 天气、标签和地点
  • 安静清爽的时间线

越用越值得回看

  • 地图回忆
  • Year in Pixels
  • 那年今日
  • 按词语、标签、心情、照片或语音备忘搜索
  • 图库 — 照片与语音备忘集中在一处
  • 模板与每日写作提示
  • 为日常、旅行、感恩等创建多本日记

把以前的日记原样带过来

  • 导入 Day One 的导出文件 — 正文、照片、日期、地点、标签都在。免费
  • 用照片补写过去的日子 — 选一段日期，那天拍的照片就成为那天的日记
  • 同一个文件导入两次也不会重复，导入可以撤销

拥有自己的记录

  • Face ID / Touch ID 锁定
  • 导出 PDF、Markdown 或 JSON
  • 无广告追踪
  • 没有我们自己的服务器 — 你的日记不会上传给我们
  • 语音识别只在设备端进行
  • 仅从 Apple 获取地点名称与天气，可在设置中关闭
  • 可选的 iCloud 同步（默认关闭）— 你自己的私有 iCloud 数据库，开发者无法读取
  • App Store 隐私标签：未收集数据
