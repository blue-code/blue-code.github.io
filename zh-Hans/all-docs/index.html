收到的文档，用 AllDocs 直接打开，放大看得清清楚楚。

AllDocs 是一款文档查看器，把多种格式的文档整齐地集中在一处显示。文字可随意放大缩小，任何文档都能舒适阅读；文本和 Markdown 还能就地编辑并保存。

支持的格式

  • 文本（.txt）、Markdown（.md）— 查看 + 编辑
  • Word（.docx、.doc）— 查看
  • 韩文（.hwp、.hwpx）— 查看

主要功能

  • 文字放大／缩小 — 双指缩放与分级按钮，清晰易读
  • 文本与 Markdown 的编辑和保存
  • 深色模式与注重可读性的排版
  • 文档内搜索、最近文档、收藏
  • 在「文件」应用和其他应用中「用 AllDocs 打开」
  • 完全离线运行，没有广告

隐私

文档仅在本机处理，绝不会发送到任何外部。

AllDocs Pro（一次性永久购买）

无限最近文档与收藏、导出 PDF、更多主题与字体、多文档。

说明

.doc/.docx/.hwp/.hwpx 文档为只读查看，表格、图形等部分元素的版式可能与原稿不同。编辑和保存仅支持文本（.txt）和 Markdown（.md）。其他格式可导出为文本或 Markdown 后再编辑。
