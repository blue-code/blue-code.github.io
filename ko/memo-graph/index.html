MemoGraph

말하면 AI가 정리하는 지식 그래프

Productivity · iPhone · iPad · ￦9,900

App Store에서 보기

말하기만 하면 AI가 알아서 정리합니다.

MemoGraph는 일반 메모 앱이 아닙니다. "차키를 책상 서랍에 넣었어"라고 말하면, AI가 핵심 정보와 그 관계를 자동으로 추출해 개인 지식 그래프로 쌓아갑니다. 나중에 "차키 어디 있지?"라고 물으면 그래프를 탐색해 바로 답해줍니다.

이렇게 동작해요

  • 말하거나 입력하면 AI가 엔티티·별칭·위치·관계를 자동 분류
  • 물건의 위치를 옮기면 "기존 위치에서 옮길까요?"라고 확인 후 업데이트
  • 자연어로 질문하면 그래프를 따라가 답변 (위치·이력·원문 기반)
  • 서로 연결된 기억을 한눈에 보는 지식 그래프 뷰

내 데이터는 내 기기에

  • 모든 기록은 옵시디언 호환 마크다운(.md) 파일로 저장됩니다
  • 볼트 폴더를 옵시디언에서 열면 [[위키링크]]가 그대로 동작
  • 로컬 저장 또는 iCloud 동기화 중 선택 가능
  • 지원 기기에서는 온디바이스 AI로 처리할 수 있습니다. 클라우드 AI를 사용할 경우, 입력/음성 텍스트와 대화 맥락을 Google Gemini로 보내기 전에 앱 안에서 전송 데이터와 받는 곳을 안내하고 동의를 받습니다

주요 기능

  • AI 자동 분류: 자연어 → 엔티티 + 관계 + 별칭 추출
  • 양방향 지식 그래프: A→B 관계 시 B→A 백링크 자동 생성
  • 위치 충돌 감지: 물건을 옮기면 이전 위치 확인 대화
  • 음성 입력: 온디바이스 한국어 음성 인식
  • 위치 이력: 현재·과거 위치를 시간순으로 확인
  • 카테고리 탐색·검색: 물품·장소·사람·일정·아이디어별 정리

생각나는 대로 말하세요. 정리는 MemoGraph가 합니다.

※ 클라우드 AI 분류 기능을 사용하려면 설정에서 Google Gemini API 키를 입력하고, 데이터 전송 전 앱 안의 클라우드 AI 동의 안내에 명시적으로 동의해야 합니다.
