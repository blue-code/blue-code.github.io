Compendium Lab: 수학·AI 강의

컴퓨터과학·파이썬·머신러닝 오프라인 학습

Education · iPhone · iPad · 무료 다운로드

App Store에서 보기

수학, 컴퓨터 과학, 인공지능의 핵심 개념을 한곳에서 공부하세요.

18개 챕터와 94개 강의를 한국어, 영어, 일본어, 중국어로 오프라인에서 읽고, 수식과 도표를 선명하게 확인할 수 있습니다. 진도와 북마크, Python 실습 초안은 기기에 저장되며 사용자의 비공개 iCloud로 동기화할 수 있습니다. 지원되는 Python 예제는 서버 전송 없이 기기에서 직접 실행됩니다.

누적 읽기, 소제목 회상, 직접 구현으로 이어지는 학습 세션을 통해 읽는 데서 그치지 않고 개념을 자기 것으로 만들어 보세요.

구성

  • 18개 챕터 94개 강의: 선형대수, 미적분, 확률, 통계, 알고리즘, 자료구조, 컴퓨터 비전, 그래프 신경망, 응용 AI
  • 모든 강의의 4개 언어 에디션 - 리더 툴바에서 즉시 전환
  • 온디바이스 Python 실습실: 모든 코드 블록을 편집하고, 지원되는 예제는 서버 없이 바로 실행
  • 강의마다 생성되는 누적 복습과 백지 회상 세션
  • 진도, 북마크, 실습 초안은 기기 저장 후 개인 iCloud로만 동기화

가격

1~2챕터는 전체를 무료로 읽을 수 있습니다. 1회 결제로 18개 챕터 전체와 Python 실습실이 모두 열립니다. 구독 없음, 광고 없음, 계정 없음.

개인정보

분석 도구, 광고, 트래킹을 사용하지 않습니다. 강의와 Python 런타임이 앱에 포함되어 있어 네트워크 연결 없이 동작합니다.
