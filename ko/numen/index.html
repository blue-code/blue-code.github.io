"공식을 외우는 게 아니라, 이해하기 시작하는 순간."

NUMEN은 문제집 앱이 아닙니다.

수학을 포기했던 사람이, 다시 수학적 직관을 회복하는 앱입니다.

이 앱은 다릅니다

기존 수학 앱:

정의 → 공식 → 풀이 → 오답

NUMEN

체험 → 패턴 발견 → 직관 → 정의

손가락으로 직접 만지고, 슬라이더를 움직이고, 값이 변하는 걸 눈으로 봅니다. 분수 한 조각, 함수 그래프 한 점, 음수의 방향 — 모든 개념이 "움직이는 수학"으로 다시 살아납니다.

누구를 위한 앱인가요?

  • 수업이 끊겨 수학을 포기한 중·고등학생
  • 학원식 설명에 지친 분
  • 투자·통계·AI를 이해하고 싶은 직장인
  • "그때 멍청해서 못한 게 아니다"를 다시 느끼고 싶은 모든 분

핵심 기능

  • 손가락으로 만지는 인터랙티브 레슨

  • 직관 우선의 단계별 흐름

왜 NUMEN인가요?

수학을 못한 게 아닙니다.

개념과 개념 사이의 연결이 끊어졌을 뿐입니다.

NUMEN은 그 연결을 — 손으로 다시 잇도록 — 설계됐습니다.

"아, 내가 멍청했던 게 아니라

연결이 끊겨 있었던 거구나."

이 한마디를 다시 만나보세요.

프라이버시 우선

NUMEN은 어떠한 개인정보도 수집하지 않습니다. 모든 학습 진도는 기기 안에만 저장됩니다. 광고 SDK, 분석 도구, 외부 API — 모두 없습니다.

가격

  • 앱 다운로드 — 무료
  • Phase 1–3 (12 레슨, 약 60분 분량) — 무료
  • Phase 4–10 (21 레슨) — 단일 인앱 구매로 평생 잠금 해제. 광고도, 구독도, 갱신도 없습니다.

향후 업데이트 예정

  • Phase 5–10 콘텐츠 확장 (각 페이즈 추가 레슨)
  • 학습 회고·메모 화면
