하루담: 비공개 오프라인 일기

음성메모·지도·잠금 다이어리

Lifestyle · iPhone · iPad · 무료 다운로드

App Store에서 보기

하루를 담다, 하루담.

하루담은 구독 없이 쓰는 비공개 일기장입니다. 사진, 장소, 감정으로 하루를 남기세요. 길게 쓰지 않아도 괜찮아요. 한 줄, 사진 한 장, 오늘의 기분만 남겨도 시간이 지나면 나만의 기억 지도가 됩니다.

계정 가입은 없습니다. 구독도 없습니다. 기본은 이 기기 안입니다. 아이패드와 이어서 쓰고 싶다면 iCloud 동기화를 직접 켤 수 있어요.

오늘의 순간을 빠르게 남기기

  • 한 줄 일기 — 30초 안에 오늘의 장면 기록
  • 음성 메모 — 말로 남긴 하루가 기기 안에서 글로 바뀝니다
  • 받아쓰기 — 마이크를 누르고 말하면 그대로 본문에 들어옵니다
  • 서식 도구 — 제목, 인용, 목록, 체크박스
  • 사진 일기 — 하루의 분위기를 사진과 함께 보관
  • 동영상 — 고른 화질로 줄여서 한 편씩 담기
  • 그림과 스캔 — 애플펜슬로 그리고, 옛 편지는 스캔해서 남기기
  • 기분 기록 — 좋음, 평온, 흐림 같은 감정 흐름 저장
  • 장소와 날씨는 자동으로 — 며칠 뒤에 쓰는 일기도 그날의 날씨로
  • 사진을 넣으면 찍힌 날짜로 옮길지 물어보고, 그 사진의 장소를 씁니다
  • 날씨, 태그, 장소 — 나중에 찾기 쉬운 맥락 추가
  • 타임라인 — 쌓인 하루를 차분하게 다시 보기

시간이 지나면 더 좋아지는 기록

  • 캘린더 기분 히트맵 — 한 달의 감정을 색으로 보기
  • 지도 회상 — 내가 기록한 장소를 지도 위에서 다시 걷기
  • Year in Pixels — 나의 한 해를 한눈에 돌아보기
  • 그날의 기억 — 1년 전, 3년 전 오늘 다시 만나기
  • 검색 — 단어, 태그, 기분, 사진, 음성 메모로 바로 찾기
  • 갤러리 — 사진과 음성 메모를 한자리에서
  • 템플릿과 오늘의 글감 — 무엇을 쓸지 막힐 때

쓰던 일기를 그대로 가져오기

  • 데이원(Day One) 내보내기 파일 가져오기 — 글, 사진, 날짜, 장소, 태그까지. 무료입니다
  • 사진으로 지난 날 채우기 — 날짜 구간을 고르면 그날 찍은 사진이 그날의 일기가 됩니다
  • 같은 파일을 두 번 가져와도 겹치지 않고, 가져오기는 되돌릴 수 있습니다

내 기록을 내가 소유하기

  • Face ID / Touch ID 잠금
  • PDF, Markdown, JSON 내보내기
  • 광고 추적 없음
  • 우리 서버 없음 — 일기가 우리에게 업로드되는 일은 없습니다
  • 음성 인식은 기기 안에서만 처리
  • 장소 이름과 날씨만 Apple에서 받아오며, 설정에서 끌 수 있습니다
  • 선택형 iCloud 동기화(기본 꺼짐) — 내 비공개 iCloud 저장소, 개발자는 볼 수 없음
  • 앱스토어 개인정보 라벨: 데이터 수집 없음

무료로 시작하고, 필요할 때 평생 잠금 해제

무료로 기본 일기를 계속 쓸 수 있습니다.

하루담 Pro는 한 번 구매로 평생 사용할 수 있습니다. 자동 갱신되는 월 구독이 아닙니다.

Pro 포함:

  • 무제한 저널
  • 일기당 사진·동영상 무제한
  • 지도 회상
  • Year in Pixels와 고급 통계
  • PDF / Markdown / 데이원 형식 내보내기
  • 템플릿
  • 추가 테마와 커스텀 태그

이런 분께 잘 맞아요

  • 사진과 함께 하루를 남기고 싶은 분
  • 일기를 클라우드에 맡기기 불안한 분
  • 구독 없는 평생 기록 도구를 원하는 분
  • 감정의 흐름을 조용히 돌아보고 싶은 분
  • 여행, 육아, 연애, 일상을 오래 보관하고 싶은 분
