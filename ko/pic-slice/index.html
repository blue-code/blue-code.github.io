내 사진으로 즐기는 오프라인 슬라이드 퍼즐

픽슬라이스(PicSlice)는 내 사진으로 즐기는 오프라인 사진 퍼즐/슬라이드 퍼즐 게임입니다. 사진을 3×3부터 6×6까지 정사각 타일로 나누고, 클래식 15퍼즐처럼 한 조각씩 밀어 다시 맞춰보세요. 출퇴근길 1분 컷도, 주말의 30분 도전도 모두 좋습니다.

핵심 기능

  • 3가지 게임 모드
  • Slide: 빈 칸 하나로 인접 조각을 미는 클래식 모드
  • Free Swap: 임의의 두 조각을 탭으로 교환하는 자유 모드
  • Time Attack: 60/90/120초 안에 완성하는 스피드 모드
  • 4단계 난이도: 3×3 / 4×4 / 5×5 / 6×6 (그리드가 곧 난이도)
  • 사진 소스 3가지
  • 큐레이션된 샘플 갤러리 (즉시 플레이 가능)
  • 사진 보관함에서 가져오기 (PHPicker 사용 — 권한 다이얼로그 없음)
  • 카메라로 직접 촬영
  • 개인 통계: 베스트 타임 / 평균 무브 / 클리어 횟수 (그리드별 · 모드별)
  • 햅틱 피드백 + 부드러운 애니메이션 60fps
  • 한국어 / English / 日本語 / 简体中文 지원
  • 다크 모드 + 다이내믹 타입 + VoiceOver

정말 안전한 프라이버시

  • 인터넷 통신 0%. 사진은 단말기 밖으로 한 톨도 나가지 않습니다.
  • 광고 0%, 트래커 0%, 회원가입 0%, IDFA 0%.
  • 100% 오프라인 — 비행기 모드에서도 동일하게 동작합니다.

이런 분께 추천합니다

  • 광고와 결제 유도가 없는 단순하고 깔끔한 퍼즐을 찾는 분
  • 가족·연인·반려동물 사진을 매일 다른 퍼즐로 다시 보고 싶은 분
  • 짧은 시간 동안 두뇌를 가볍게 풀어주고 싶은 분
  • 디자인이 예쁜 앱을 좋아하는 분

지금 바로 픽슬라이스를 시작하고, 추억을 한 조각씩 다시 맞춰보세요.
