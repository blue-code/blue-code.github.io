런스탬프

러닝을 감성 포스터로 · 인스타 공유

Health & Fitness · iPhone · iPad · 무료 다운로드

App Store에서 보기

런스탬프 — Apple Watch·아이폰으로 기록한 러닝을 감성적인 포스터와 다이어리로 남기는 러닝 기록 앱.

거리·시간·페이스·심박·경로를 자동으로 정리하고, 오늘의 기분과 한 줄 메모를 더해 인스타그램에 바로 공유할 수 있는 한 장의 이미지로 만들어줍니다.

빠른 러너가 아니어도 괜찮습니다. 짧은 거리여도, 느린 페이스여도, 오늘 나가서 뛰었다면 충분히 기록할 가치가 있습니다.

러닝 포스터 자동 생성

러닝을 마치고 앱을 열면 포스터 후보가 바로 떠요. 스토리 9:16 · 피드 1:1 · 세로 4:5, 원하는 비율로 저장하고 공유하세요.

7가지 감성 템플릿 · 내 사진을 배경으로

Minimal Run, Night Runner, Slow But Done 등 7가지 템플릿. 오늘 찍은 사진을 배경으로 깔고 드래그·줌으로 구도를 잡아 문구를 얹을 수 있어요.

초보 친화 문구

느린 페이스는 "느림"이 아니라 Easy로, 걷기가 섞인 러닝은 Run-Walk로 번역돼요. 느린 러너도 부끄럽지 않게 자랑하세요.

감정 기반 문구·해시태그 자동 추천

오늘의 기분을 고르면 어울리는 한 문장과 해시태그가 자동으로 완성돼요.

스탬프 배지

First Run · 5K Done · Slow But Done … 러닝을 쌓을수록 배지가 모여요.

안전하게 공유하는 프라이버시 보호 (기본값)

집 근처 경로 자동 숨김 · 시작/종료점 흐리기 · 경로 라인아트 변환. 사진 배경 포스터에는 GPS·주소가 들어가지 않아요.

월간 리포트

이번 달 총거리·횟수·최다 감정·"이번 달의 문장"을 한 장으로.

완전 온디바이스

모든 데이터는 기기 안에서만 처리됩니다. 서버 업로드도, 계정도, 광고도, 추적도 없습니다. 건강 데이터는 읽기 전용으로만 사용하며 절대 기록하지 않습니다.

무료로 러닝 불러오기와 기본 포스터·기본 프라이버시 보호를 이용하세요. 구독 없이 평생 Pro(₩4,000, 한 번 결제)로 프리미엄 템플릿, 사진 배경, 라인아트, 워터마크 제거까지.

오늘 뛴 러닝, 예쁘게 남기세요.
