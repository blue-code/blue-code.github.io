받은 문서, 올독스로 바로 열어 크게 읽으세요.

올독스는 여러 형식의 문서를 한 곳에서 깔끔하게 보여주는 문서 뷰어입니다. 글자 크기를 자유롭게 키우고 줄여 어떤 문서든 편하게 읽을 수 있고, 텍스트와 마크다운은 그 자리에서 편집·저장까지 됩니다.

지원 형식

  • PDF(.pdf) — 보기 (한글 등 CJK 글꼴 지원)
  • 텍스트(.txt), 마크다운(.md) — 보기 + 편집
  • 코드·구조화 텍스트(.json .js .ts .py .java .c .go .sql .yaml .csv .html .xml 등) — 보기 + 편집
  • 워드(.docx, .doc) — 보기
  • 한글(.hwp, .hwpx) — 보기 (첫 페이지 미리보기 이미지 + 표 복원)
  • 엑셀(.xlsx, .xls), 파워포인트(.pptx, .ppt) — 보기
  • 전자책 EPUB(.epub) — 보기

주요 기능

  • 글자 확대/축소 — 핀치 줌과 단계 버튼으로 또렷하게
  • 텍스트·마크다운 편집과 저장
  • 다크 모드와 가독성 중심 타이포그래피
  • 문서 내 검색, 최근 문서, 즐겨찾기
  • 파일 앱·다른 앱에서 "올독스로 열기"
  • 완전한 오프라인 동작, 광고 없음

프라이버시

문서는 오직 기기에서만 처리되며 외부로 전송되지 않습니다.

올독스 Pro (평생 1회 구매)

무제한 최근 문서·즐겨찾기, PDF 내보내기, 추가 테마와 폰트, 다중 문서.

안내

.doc/.docx/.hwp/.hwpx 문서는 보기 전용이며, 표·도형 등 일부 요소의 레이아웃이 원본과 다르게 보일 수 있습니다. 편집·저장은 텍스트(.txt)와 마크다운(.md)에서 지원합니다. 그 외 형식은 텍스트·마크다운으로 내보내 편집할 수 있습니다.
