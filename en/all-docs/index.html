Got a document? Open it in AllDocs and read it big and clear.

AllDocs is a document viewer that opens many file formats in one tidy place. Zoom the text up or down to read anything comfortably, and edit and save text and markdown right where you are.

Supported formats

  • PDF (.pdf) — view (with CJK/Korean font support)
  • Text (.txt), Markdown (.md) — view + edit
  • Code & structured text (.json .js .ts .py .java .c .go .sql .yaml .csv .html .xml and more) — view + edit
  • Word (.docx, .doc) — view
  • Hangul (.hwp, .hwpx) — view
  • Excel (.xlsx, .xls), PowerPoint (.pptx, .ppt) — view
  • EPUB e-books (.epub) — view

Key features

  • Text zoom in/out — pinch to zoom and step buttons for clarity
  • Edit and save text and markdown
  • Dark mode and readability-focused typography
  • In-document search, recent files, favorites
  • "Open in AllDocs" from the Files app and other apps
  • Fully offline, no ads

Privacy

Your documents are processed only on your device and are never sent anywhere.

AllDocs Pro (one-time lifetime purchase)

Unlimited recent files and favorites, PDF export, extra themes and fonts, and multiple documents.

Please note

.doc/.docx/.hwp/.hwpx documents are view-only, and the layout of some elements such as tables and shapes may look different from the original. Editing and saving are supported for text (.txt) and markdown (.md). Other formats can be exported as text or markdown for editing.
